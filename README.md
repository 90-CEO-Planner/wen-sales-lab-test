# WEN Sales Lab (test build, M1)

Static front end for the WEN Sales Lab test environment. Contains **no curriculum text** and **no secrets**: lessons are served from the database only to signed-in, entitled members. The Supabase publishable key in `config.js` is designed to be public; all access is enforced by row-level security and checked server-side functions.

Test build only. Fictional data only.
